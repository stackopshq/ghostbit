The short version

Ghostbit is built so that there is almost nothing to disclose. No accounts, no cookies, no analytics, no advertising, no fingerprinting, and not a single request from your browser to a third party: scripts, fonts and styles are all served from this origin. Pastes are encrypted in your browser before anything reaches us; the decryption key lives in the URL fragment (#…), which browsers never transmit. We could not read your pastes if we wanted to.

Expired pastes are removed on first access, and a background sweep purges the remainder within the hour. Encrypted backups (age public-key encryption; the plaintext export never touches disk) are kept for 30 days, then deleted.

What the server does not collect

No IP addresses and no User-Agent strings: access logging is off by default and stays off on this instance unless its operator says otherwise above. The rate limiter examines the client address of each request in memory and keeps no log of it. Pastes carry no creator identity: we cannot tell who created what, which also means we cannot answer "give me everything you have about me" with anything but this page (GDPR art. 11: we hold nothing that identifies you).

Browser storage

No cookies. Three keys of plain browser storage, none of which leave your machine: your theme choice and a collapsed-hero flag (localStorage), and a tab-scoped one-time marker that shows the "paste created" banner exactly once (sessionStorage).

Third parties

When the operator fronts this instance with a CDN or reverse proxy (ghostbit.dev uses Cloudflare), that provider processes connection metadata as the operator's processor under its own data-protection terms. The server itself makes at most one outbound call: it asks the GitHub API for this project's star count, once an hour, from the server; your IP is never part of that, and air-gapped installs disable it entirely. Webhook notifications go only to the URL the paste creator supplied.

Your rights

Under the GDPR and the nLPD you can ask for access, rectification, deletion, and the rest. Concretely: deletion is self-service (whoever holds a paste's delete token can delete it instantly, no questions asked); for anything else, contact us.
